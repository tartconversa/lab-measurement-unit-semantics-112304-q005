# 资料契约

所有记录均为本地合成数据，使用 UTC 时间或 ISO 日期。标识字段用于关联文件，版次、状态、缺失、撤回和待审核值保留各自原始含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `measurement_sources.csv` | `source_id`, `lab_id`, `instrument_model`, `metric_code`, `source_unit`, `basis_code`, `schema_version` | 40 |
| `unit_dictionary.csv` | `unit_code`, `dimension`, `scale`, `offset`, `standard_version`, `valid_from` | 48 |
| `observations.csv` | `observation_id`, `source_id`, `sample_id`, `metric_code`, `value`, `unit_code`, `basis_code`, `observed_at` | 150 |
| `basis_rules.csv` | `metric_code`, `basis_code`, `required_fields`, `comparability_group`, `approval_state`, `rule_version` | 48 |

缺失值、争议状态、部分成功和待复核均不表示零值或已完成。原始值不预置分析结论，转换依据及研究解释须由应用能力提供。
