# 实验数据单位与基准条件迁移的语义化装载

数据目录由本地合成科研记录组成，不包含真实实验室、研究人员或实验结果。使用 Python 3.11 至 3.14 和标准库（含 SQLite），无需外部服务。

## 能力概览

- **可配置异构装载**（`loader.py`）：CSV/JSONL、宽表/长表，列名到科学量的绑定必须在来源配置中显式声明；原始层不可变。
- **语义校验与标准化**（`registry.py` + `validation.py`）：量纲、测量性质（绝对量/差值/设定值）、基准条件三重校验；缺基准的旧结果只进受限数据集并保留原单位，绝不补造换算值。
- **版本化共享数据集**（`repository.py` + `dataset_engine.py`）：注册表与数据集均带版次；标准修订后重算，可逐行查询转换/排除/保留历史与完整血缘；同名列不同语义会产生冲突告警而非自动合并。

## 测试

```sh
python3 -m unittest discover -s tests -v
```

Windows PowerShell 可运行 `python -m unittest discover -s tests -v`。
